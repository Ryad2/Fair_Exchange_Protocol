The goal is not to introduce new measurements, but to make the accounting recomposable in
one place. All values are gas units measured from Hardhat transaction receipts unless
explicitly stated otherwise.

For the 1 GiB hardcoded path with external sponsors and three Step 7--8 iterations, the
measured dispute after trigger is 23,865,946 gas. Including the trigger gives 26,585,279
gas, and including the optimistic path gives 29,532,277 gas. This value is not obtained by
multiplying the one-iteration path by three, because later iterations update storage slots
that have already been initialized.
